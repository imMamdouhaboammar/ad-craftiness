## 🎯 فكرة الـ Skill وميزاته الرئيسية

1. **توثيق دقيق غير قابل للتأليف (Source-Locked & Anti-Slop):** المساعد ملتزم بنص المحاضرة وشواهد التوقيت بالدقيقة والثانية.
2. **فصل قاطع وصارم في الإجابات:**
   - **قال في المحاضرة:** ما ورد نصاً على لسان فاروق مع ذكر توقيت الدقيقة والثانية.
   - **تطبيق مقترح:** توليد أفكار مستلهمة من المنهجية مطبقة على الـ Brief الخاص بك ومميزة بعلامة واضحة.
   - **مش مذكور في المحاضرة:** في حال كان السؤال خارج إطار الورشة، يعترف المساعد مباشرة ولا يخترع نظريات وهمية.
3. **متوافق مع مختلف منصات الذكاء الاصطناعي (Omni-Agent Compatible):**
   - OpenAI ChatGPT / Codex Plugins
   - Anthropic Claude Code
   - Cursor
   - Google Antigravity & Gemini CLI
   - Local CLI (Python)

## 🚀 كيفية التثبيت والاستخدام | Installation & Usage

### 1. الاستخدام كـ ChatGPT / OpenAI Codex Plugin
المستودع مهيأ بالكامل بملفات `.codex-plugin/plugin.json` المتوافقة مع معايير OpenAI الرسمية:
1. انسخ مسار المستودع أو ثبّت الـ Plugin محلياً.
2. اطلب في المحادثة مباشرة:
   - `بسأل فاروق: إزاي أبدأ مع Brief جديد ومش عارف أطلع له فكرة؟`
   - `اشرح لي الـ Concept Build-up بالمثال اللي في المحاضرة`
   - `اديني 3 اتجاهات لحملة إعلانية بناءً على الـ Brief ده، وعلّم اللي من استنتاجك`

### 2. الاستخدام في Claude Code و Agent Skills المتوافقة
انسخ مجلد `skills/ask-farouk-creative-thinking` داخل مجلد الـ skills الخاص بمشروعك أو بيئتك.

### 3. الاستخدام عبر الطرفية (CLI Search)
يتضمن المستودع أداة بحث نصية نقية وسريعة بدون أي dependencies خارجية:
```bash
python3 scripts/search.py "وبعدين" --context 2
python3 scripts/search.py "Concept" --context 1
```
